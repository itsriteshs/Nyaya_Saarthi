## Behavior
- State names are normalized against the existing jurisdiction catalog using Unicode/case/spacing normalization and conservative string similarity, not a list of user-case spellings. A correction needs score>=0.88 and margin>=0.08 over the next candidate; short/ambiguous/unmatched names stay unresolved. Original spelling is retained and any correction is shown for verification. A model's canonical State value is accepted only when the actual quoted spelling independently matches the same catalog entry.
- Unitless reported speeds can default to km/h for this India-focused application. This is a product assumption, not a claim that Indian users can never mean another unit. unitSource=context_default and a visible interpretation note distinguish it from a stated unit. Mandatory user verification remains before legal guidance. NYAYA_ASSUME_INDIAN_SPEED_KMPH=false restores unknown-unit clarification. Explicit mph is not silently treated as km/h; conversion remains unresolved.
- Relative dates get a trusted server reference in India time when the caller supplies none or supplies a naive reference. A timezone-aware reference is converted to India time. Today/aaj/आज resolve to that date, yesterday to the prior date. Ambiguous kal/कल and ambiguous numerical dates remain unresolved. The SLM still extracts the actual source words; the model does not invent a calendar date.
- A genuine unit-only answer has its own supported OBSERVED_SPEED_UNIT field. The SLM receives the existing facts and active question. Validated unit answers merge with the saved speed, retaining history and requiring confirmation. A model mislabelling km/h as OBSERVED_SPEED can be safely type-normalized to the unit field, avoiding the former UNSUPPORTED_SPEED_VALUE error. Numeric values with a stated supported unit can likewise be normalized rather than rejected for not being digits-only.
- Location/road/police contextual descriptions are additive. Different descriptions alone do not establish a contradiction or an impossible timeline. Multiple resolved contextual descriptions are aggregated for slot readiness without discarding their separate fact records. Conflicting numerical speeds, States and other single-value facts still require clarification.
- Strict malformed-schema and unsupported legal-content checks remain. Within a schema-valid extraction, one ungrounded mention is quarantined in rejectedMentions instead of erasing other grounded facts. If all nonempty mentions are invalid, intake still returns a visible retryable error. Nothing is silently promoted to a user-stated fact.
